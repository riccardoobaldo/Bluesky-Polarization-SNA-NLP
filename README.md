# Dinamiche di Polarizzazione Digitale: Woke vs anti-Woke

Un'analisi multidimensionale del confronto ideologico tra narrazioni contrapposte sul social network Bluesky. 

## Descrizione del Progetto
Il progetto analizza la struttura e le dinamiche del dibattito utilizzando tecniche di:
- **Social Network Analysis (SNA):** Costruzione del grafo, identificazione delle echo chambers, analisi dell'assortatività e calcolo del coefficiente di Gini.
- **Natural Language Processing (NLP):** Analisi del sentiment, identificazione dei vocabolari identitari e misurazione dell'indice di tossicità.
- **Machine Learning:** Modelli predittivi bilanciati per la classificazione dello stance (Woke, Anti-Woke, Neutrali).

## Tecnologie Utilizzate
- Python (Pandas, Numpy)
- Rete e API: Atproto (Bluesky API), NetworkX, Python-Louvain
- Machine Learning & NLP: Scikit-learn, Torch, Transformers, Hugging Face
